---
title: "気象・海洋のデータ（NetCDF）"
---

気象・気候・海洋の格子のデータを、単位付きの値のまま見て、測る。

## 開ける形式

NetCDF のファイル（`.nc` `.nc4` `.cdf` `.netcdf`）を、写真と同じようにフォルダから開きます。NetCDF-3（classic、64bit オフセット、64bit データ）と NetCDF-4 を読めます。NetCDF でない HDF5 と HDF4 は、まだ開けません。

2 次元以上の数値の変数を、1 枚の画像にします。最初に出るのは、1 面がいちばん大きい変数です。

## 変数を切り替える

1 つのファイルに、気温・降水・風のような変数がいくつも入っているのが普通です。

- **N** で次の変数、**Shift+N** で前の変数に切り替えます
- 画像の上で右クリック →「変数」で、一覧から選べます。今の変数に印が付き、項目にマウスを置くと次元が出ます。グループの中の変数も選べます
- 時刻や高さは、1 つのスロットの中の面として並び、ホイールで送ります。右下の札に「time = 2024-01-18 06:00」のように、面の時刻や高さが出ます。変数を切り替えても、同じ番目の面のままです

## 値のまま測る

画素は、ファイルの値に `scale_factor` と `add_offset` を当てて戻した値（K など、`units` の単位付き）で持ちます。

- [画素の値の確認](check.html)（V）、ROI、計測線のグラフ、色のゲージが、その値と単位を使います。`scale_factor` のある変数では、計測線のグラフにファイルに入っている値も並べて出します
- 値のない画素（`_FillValue`、`missing_value`、`valid_range` の外。海のデータの陸など）は、設定の「欠損の画素の色」で描きます。色の表を当てても、この色のままです
- 緯度が南から北へ並ぶデータは、上下を返して北を上にします（設定の「北を上にする」で切れます）

## 色と黒と白

- 初めから色の表（既定は viridis）を当てて表示します。色の表は設定の「NetCDF のデータ」で変えられます
- 黒と白は、変数ごとに、全部の時刻・高さから 1 つ決めます。面を送っても色の付き方が変わらないので、時刻どうしを比べられます。気温と降水のように単位が違うので、変数ごとに別に決めます
- 名前（`sst_anom` など）・`standard_name`・`long_name` に anomaly や偏差が入った変数（平年との差）は、自動で 0 から対称の黒と白にし、0 を真ん中にした色の表（coolwarm）を当てます。設定の「偏差は 0 を真ん中に」で切れます
- 風のようにほかの 0 をはさむデータは、設定の「最初の黒と白」を「0 から対称」にすると、0 が色の表の真ん中になります
- ゲージで手で変えた黒と白は、変数を切り替えると元に戻ります

## 緯度・経度と時刻・高さ

ファイルに緯度・経度が書いてあれば、画素ごとの位置を読みます。読めるのは次の形です。

- 緯度と経度が 1 次元の軸になっている格子（いちばん多い形）
- 緯度と経度が 2 次元の表になっている曲がった格子（変数の `coordinates` 属性で指すもの。海洋のモデルなど）
- 図法の格子（`grid_mapping` で指す、x / y が m や km の格子）。ランベルト正角円錐図法、ポーラーステレオ図法、メルカトル図法、横メルカトル図法、アルベルス正積円錐図法、回転極を、緯度・経度に直します

位置が分かると、次のところに出ます。

- [画素の値の確認](check.html) の十字の横と、左下のカーソルの位置の値に、値と位置に続けて「35.68°N 139.77°E  time = 2024-01-18 06:00」のように緯度・経度と面の時刻・高さを出します。**Ctrl+C** でコピーすると、緯度・経度（南と西は負の数）と面の札を、値のあとにカンマで並べます
- 計測線の長さ（線の横の札）と、計測線のグラフの横軸を、地球の上で線に沿って測った km にします。表の始点と終点に緯度・経度を、CSV に `distance_km`・`latitude`・`longitude` の列を足します。緯度・経度の分からない線が混ざっているときは、全部を画素で測ります
- ROI のグラフの「フレームごとの平均」の横軸に、フレームの番号のかわりに面の日時や高さを出します。CSV に `plane` の列を足します
- [地図](find.html#地図で撮影地点を見る) に、開いているフォルダの NetCDF のファイルの範囲を赤い枠で描きます。枠か真ん中の点を押すと、写真と同じく名前が出て、開けます。範囲が重なっているときは、小さいほうを選びます
- キーの「スロットのデータの範囲を地図で見る」で、今のスロットの範囲が入るように地図を開いて合わせます。初めはキーを割り当てていないので、設定のキーの割り当てで付けてください

経度が 0〜360° の格子（日本が左寄り、アメリカが右寄りに出るもの）は、設定の「経度を −180〜180° に回す」で、左端が西経 180° になるよう並べ替えられます。グラフや CSV の画素の位置も、並べ替えた後のものになります。

## メタデータと検索

メタデータの欄に、今の変数の属性（「NetCDF variable」）、ファイルの全部の変数（「NetCDF variables」）、ファイル全体の属性（「NetCDF global attributes」）を出します。[データセット](find.html) の検索カタログにも入るので、変数の名前や属性で探せます。

## 設定

設定の「地球科学の格子のデータ (NetCDF)」にまとめてあります。

| 項目 | 内容 | 初期値 |
| --- | --- | --- |
| NetCDF のデータ | 色の表の段を初めから入れるかと、その色の表 | 入れる、viridis |
| 最初の黒と白 | パーセンタイル / 0 から対称 など | パーセンタイル |
| 黒にする割合・白にする割合 | パーセンタイルのときの割合 | 0.5% ・ 99.5% |
| キューブの面で黒と白を揃える | 変数の全部の面から黒と白を 1 つ決める。切ると面ごと | 有効 |
| 北を上にする | 緯度が南から北へ並ぶデータの上下を返す | 有効 |
| 欠損の画素の色 | 値のない画素の色 | 灰色 |
| 座標を出す | 十字・計測線・ROI のグラフ・地図に、緯度・経度と面の時刻・高さを出す | 有効 |
| 経度を −180〜180° に回す | 経度が 0〜360° の格子の左端を西経 180° にする | 無効 |
| 偏差は 0 を真ん中に | 偏差の変数を 0 から対称の黒と白と coolwarm にする | 有効 |
