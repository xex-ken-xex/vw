# キー操作の一覧

[README](../../README.md) › [使い方](README.md)


すべて [設定](settings.md#キーの割り当てを変える) で変えられます。メニューの右側には、今のキーが出ます。

## 見る

| キー | 動作 |
| --- | --- |
| → / Space | 次の画像のスロット |
| ← | 前の画像のスロット |
| Ctrl+→ / Ctrl+← | 次 / 前のスロット（フォルダのスロットも含む） |
| PageDown / PageUp | 次 / 前のページ |
| Enter | スロットの最大化 / 元に戻す（フォルダのスロットでは、そのフォルダへ移る） |
| Backspace / マウスの戻るボタン | 1 つ上のフォルダへ |
| 0 | スロットに合わせる |
| Ctrl+0 | 実寸（100%） |
| + / = | 拡大 |
| - | 縮小 |
| P | スライドショーの再生 / 一時停止 |
| F5 | 全画面スライドショー |
| V | 画素値の確認の切り替え |
| R | ROI ツールの切り替え |
| Delete | 選んだ十字か ROI を消す |
| G | 色のゲージを出す / 出さない |
| D | カメラ RAW をセンサーのデータから現像 |
| J | カメラ RAW の埋め込みプレビューと現像した画像を切り替え |
| A | 自動で明るく見せる / 戻す |
| O | 白飛び・黒つぶれの印を出す / 外す |
| K | フォーカスピーキングを出す / 外す |
| Shift+O | sRGB で出せない色に印を付ける / 外す |
| Ctrl+H | 解析ウインドウ（ヒストグラム・画質の値）を開く / 閉じる |
| H | 左ドラッグを手のひら / 矢印に切り替え |
| Z | 左ドラッグをズーム / 矢印に切り替え |
| Ctrl+C | 画像をクリップボードへコピー |

## レイアウトとスロット

| キー | 動作 |
| --- | --- |
| Alt+0 〜 Alt+7 | レイアウト: 自動 / 1x1 / 1x2 / 2x1 / 2x2 / 3x3 / 4x4 / カスタム |
| Ctrl+N | スロットを追加 |
| Ctrl+W | スロットを閉じる |
| Ctrl+Shift+W | すべてのスロットを閉じる |

## タグ付け

| キー | 動作 |
| --- | --- |
| T | タグ付けモードの切り替え |
| ↑ / ↓ | 良い / 悪いのフラグ（タグ付けモードの間だけ） |
| 1 〜 9 | タグ 1〜9（タグ付けモードの間だけ） |
| Ctrl+Shift+0 | すべての画像を表示 |
| Ctrl+Shift+↑ | 良い画像だけを表示 |
| Ctrl+Shift+↓ | 悪い画像だけを表示 |
| Ctrl+Shift+U | フラグのない画像だけを表示 |
| Ctrl+E | 画像を書き出す |

## 画面

| キー | 動作 |
| --- | --- |
| Ctrl+1 / 2 / 3 / 4 | フォルダツリー / メタデータ / 画像 / ログの表示切替 |
| Ctrl+D | データセット画面を開く・閉じる |
| Ctrl+B | サブフレームのウインドウを開く・閉じる |
| Ctrl+M | 地図の表示切替（設定で地図を使うときだけ） |
| Ctrl+Z | 地図で置いた・消した位置を元に戻す |
| Ctrl+, | 設定を開く・閉じる |
| Ctrl+Q | 終了 |

## マウス

| 操作 | 動作 |
| --- | --- |
| ホイール | 画像やスロットを送る（[画像を送る](view.md#画像を送る)） |
| 左ドラッグ | 手のひらのとき画像を動かす / 矢印のとき画像をフォルダへ運ぶ |
| 右ドラッグ（上下） / Ctrl+ホイール / ピンチ | 拡大・縮小 |
| ダブルクリック | スロットの最大化 / フォルダのスロットなら中の画像を読む |
| ヘッダをドラッグ | ファイルの移動（Ctrl でコピー） |
| 右クリック | 画像・ツリー・ログのメニュー |
