画質の評価

解析ウインドウの「評価」タブと、画素の変換のウインドウに出る 5 つの指標の意味・式・目安。

使い方 PSNR SSIM SNR CNR 鮮鋭度 判定と目安 何の値で測るか

使い方

  1. 表示 → 解析 を開き、評価 のタブを選ぶ。アクティブなスロットの画像を評価する。
  2. 表の列は 変更前（ふつうの表示）と 変更後（画素の変換で値を変えた結果）。
  3. PSNR と SSIM は 2 枚を比べる指標で、既定では変更前を基準にして変更後を測る。別の画像（撮り直しや別の処理の結果）と比べたいときは、そのスロットを右クリックして 評価の基準にする。大きさ（幅・高さ）が同じ画像でないと比べられない。
  4. SNR と CNR には ROI が要る。左のツール列の ROI（R）を選び、スロットの上をドラッグすると 対象（赤の破線）、Shift を押しながらドラッグすると 背景（青の破線）。Delete で消す。ROI はフレームごとに持つ。
  5. CSV にコピー で、表をそのまま表計算ソフトへ貼れる。

計算は裏で行う。値を動かしている間は縮小した画像で追いかけ、止まったら全画素で計算し直す。

PSNR（ピーク信号対雑音比）

基準の画像との画素ごとの差の大きさ。差が小さいほど大きくなる。単位は dB。2 枚がまったく同じなら無限大（∞）。

MSE=1N∑i=1N(ai−bi)2 PSNR=10⁢log10P2MSE

a・b は 2 枚の画素、N は画素の数、P は画素の取りうる最大値（vw では表示の明るさの 255）。

画像全体の平均の差しか見ないので、目立つ所のわずかな崩れも目立たない所の大きな崩れも同じに数える。見た目の印象とずれるときは SSIM と合わせて見る。

SSIM（構造的類似度）

基準の画像と、明るさ・コントラスト・模様（構造）がどれだけ似ているか。1 が同一で、似ていないほど小さくなる。Wang ら（2004）の式。

SSIM(x,y)= (2μxμy+C1)(2σxy+C2) (μx2+μy2+C1)(σx2+σy2+C2) C1=(0.01P)2,C2=(0.03P)2
  • μ・σ²・σxy は、各画素のまわりの 11×11 のガウス窓（σ = 1.5）で重みをつけた平均・分散・共分散。
  • 画素ごとに求めた値を、窓が画像に収まる範囲で平均したものを出す。
  • 元の実装と同じく、短い辺が 256 画素ほどになるまで整数倍で縮小してから求める。SSIM は見る距離に合った解像度で比べる指標なので、大きな画像を等倍で比べると小さすぎる違いまで拾うため。

SNR（信号対雑音比）

対象 ROI の中の、明るさの平均とばらつきの比。ばらつき（ノイズ）が小さいほど大きい。ROI の中が均一なら無限大。

SNR=|μ対象|σ対象

μ は ROI の中の平均、σ は標準偏差（母標準偏差）。対象 ROI は、本来は一様に写るはずの所（平らな面、均一な部材）に置く。模様のある所に置くと、模様までノイズに数えてしまう。

CNR（コントラスト対雑音比）

対象と背景の明るさの差が、背景のノイズの何倍あるか。見分けたい物が雑音に埋もれていないかを見る。

CNR=|μ対象−μ背景|σ背景

対象 ROI と背景 ROI の両方が要る。背景のばらつきがなければ無限大。

鮮鋭度（ラプラシアンの分散）

輪郭のくっきりさ。各画素で 4 近傍のラプラシアンを求め、その分散を出す。ぼけるほど小さくなる。

Lx,y=4Ix,y−Ix−1,y−Ix+1,y−Ix,y−1−Ix,y+1 鮮鋭度=Var(L)=1M∑L2−(1M∑L)2

縁の 1 画素は除く（M は残った画素の数）。基準は要らない。ノイズも輪郭として数えるので、ノイズの多い画像では大きく出る。同じ被写体・同じ撮り方の画像どうしで比べる。

判定と目安

どの指標も値が大きいほど良い。値が「適合」の下限以上なら 適合、「注意」の下限以上なら 注意、それ未満は 劣化。

指標適合（以上）注意（以上）設定の名前
PSNR35 dB25 dBquality.psnr
SSIM0.950.85quality.ssim
SNR105quality.snr
CNR31.5quality.cnr
鮮鋭度500100quality.sharpness

表の値は既定の目安（表示の明るさ 0〜255 で測ったとき）。用途によって変わるので、設定で指標ごとに変えられる。変えるとすぐ判定だけが変わる（計算し直さない）。設定ファイルでは次のように書く。

[quality]
psnr = { good = 40, caution = 30 }
cnr = { good = 5, caution = 3 }

判定の横の帯は、適合の下限で 3/4、その 1.5 倍で満杯になる長さ。閾値の大きさが違う指標を同じ帯で見比べるためのもの。

目安の考え方:

  • PSNR: 8bit の画像では、40 dB を超えると違いはほぼ見えず、30 dB 前後で注意して見ると分かり、20 dB を切るとはっきり崩れて見えることが多い。
  • SSIM: 0.95 以上ならほぼ同じ見た目。0.9 を下回ると、模様の崩れやぼけが見えてくることが多い。
  • SNR: 画像の分野で「5 以上あれば見分けられる」とされる目安（Rose の基準）を注意の下限にした。
  • CNR: 1 だと差が雑音と同じ大きさで見落としやすい。3 以上あれば見分けやすい。
  • 鮮鋭度: 被写体と画像の大きさで大きく変わる。絶対値よりも、同じ条件の画像どうしの比べ合いに使う。100 を切る画像はピンぼけを疑う、というのがよく使われる目安。

何の値で測るか

どの指標も、表示の明るさ（0〜255）で測る。カラーの画像は明るさ（Y = 0.2126 R + 0.7152 G + 0.0722 B）にしてから測る。

「変更後」は画素の変換の結果として、表示の色としてしか存在しないので、変更前と同じ土俵に乗せるには表示の明るさで比べるしかないため。そのため、ROI の横に出る平均・標準偏差（ファイルに書かれた値で求めたもの）とは一致しない。
