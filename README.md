# vw Image Viewer

**vw Image Viewer**（以下 vw）は、Linux と Windows で動く、起動と表示がとても速い画像ビューワです。
たくさんの画像を **見て**、**選り分けて**、**探せるようにしまっておく** ための道具です。

![vw の画面](docs/screenshot.png)

紹介ページ: https://xex-ken-xex.github.io/vw/

vw でできることは、大きく分けて 3 つです。

| | できること | こんなときに |
| --- | --- | --- |
| 🖼️ | **[画像を見る](docs/manual/view.md)**<br>フォルダの画像を何枚も並べて、すばやく見比べる。拡大・縮小・スライドショー・アニメーションの再生も | 撮った写真をざっと見たい。似た写真を並べて比べたい。数千枚のフォルダでも待たされたくない |
| 🏷️ | **[タグを付ける](docs/manual/tags.md)**<br>画像に「良い / 悪い」のフラグと、自分で決めたタグ（例: 山・海・花）をキー 1 つで付ける。付けたもので絞り込み、別のフォルダへコピーしたり、一覧（CSV / JSONL）に書き出したりする | 良い写真だけを選んで残したい。失敗した写真をまとめて消したい。画像を種類ごとに分けたい（機械学習の学習データ作りなど） |
| 🗂️ | **[カタログで管理する](docs/manual/catalog.md)**<br>フォルダを「データセット」として登録すると、中の画像の撮影情報などを集めた **検索カタログ** を作る。どこに何があるかを、名前・メモ・タグ・撮影情報で探し、必要なものを取り出す | 何年分もの画像のどこに何があるか分からない。「ISO 800 以上で撮った写真が入っているフォルダ」のように中身で探したい |

ほかにも、次のような特長があります。

- **速い**: 起動してすぐ使えます。画像の読み込みは裏で並行して行い、表示は GPU で描きます
- **値を落とさない**: 16bit の画像も 8bit に落とさずに読み込み、画素の値・計測・書き出しは元の階調のまま扱います。10bit・12bit を出せるモニタなら、画面にもその階調で描けます（[8bit より深く表示する](docs/manual/view.md#8bit-より深く表示する10bit12bit-以上)）
- **画像ファイルを書き換えない**: タグやカタログは別のファイルに保存します。元の画像には一切手を加えません
- **ZIP / 7z / tar の中もそのまま見られる**: パスワード付きの ZIP・7z も開けます
- **日本語表示**: メニューや設定を日本語で表示できます（初めて起動したときは OS の言語に合わせます。[切り替え方](#日本語表示にする)）
- **無料・オープンソース**: MIT / Apache-2.0 のデュアルライセンスです

### どの形式でもできること: 整理して、探す

JPEG でも RAW でも FITS でも、ZIP の中の画像でも、整理と検索は同じ操作でできます。

**整理する**

- **キー 1 つで選り分ける**: 「良い / 悪い」のフラグと自分のタグを付け、付けたもので絞り込み、別のフォルダへコピーしたり、CSV / JSONL の一覧にしたりします（[タグを付ける](docs/manual/tags.md)）
- **AI に任せる**: 写っているもののタグと、人の顔に名前を付けます。モデルは PC の中で動き、画像を外へ送りません（[AI タグと顔](docs/manual/tags.md#ai-タグと顔)）
- **似た画像を見つけて比べる**: RAW と JPEG、撮り直し、連写のような似た画像を組にし、重ねて違いを測ります（[似た画像を位置合わせして比べる](docs/manual/view.md#似た画像を位置合わせして比べる)）
- **ラベルと一緒に動かす**: ドラッグで移動・コピーしても、フラグとタグが付いてきます。悪い画像はまとめてごみ箱へ送れます

**探す**

- **中身で探す検索カタログ**: フォルダを「データセット」として登録すると、形式ごとの情報（JPEG の撮影情報、PNG のテキスト、TIFF のタグ、FITS のヘッダなど）を、ZIP / 7z の中まで集めます。「ISO 800 以上」「この望遠鏡で撮った」のように中身で探し、見つけた画像だけを取り出せます（[カタログで管理する](docs/manual/catalog.md)）
- **AI タグと人の名前でも探す**: 付けた AI タグや人物の名前も、検索カタログの条件になります
- **地図で探す**: 撮影地点のある写真を地図に点で出し、地名で探せます。位置のない写真には、地図に置いて撮影地点を付けられます（[地図で撮影地点を見る](docs/manual/view.md#地図で撮影地点を見る)）
- **星図で探す**: 天体の画像が空のどこを写したかを星図に出します（[星図で写した範囲を見る](docs/manual/view.md#星図で写した範囲を見る)）

**見る・測る**

- 何枚も並べて見比べる、スライドショー、フォルダに増えた画像を自動で表示する
- 画素の値・ROI・ヒストグラム・画質の値（PSNR・SSIM など）を測る
- 画素の変換（黒と白、曲線、色の表、式などのノード）を見て変え、同じ変換を `vwbatch` でまとめて書き出す
- 白黒の画像に色の表を当てる（**C** キー）、QR コードを読む、ほかのアプリへ送る

### 形式ごとにできること

形式によって持っている情報が違うので、vw でできることも少しずつ違います。

| 形式 | その形式ならではのこと |
| --- | --- |
| JPEG | EXIF の向きで正しく表示し、カメラ・レンズ・露出などの撮影情報を出す。GPS があれば地図に出し、撮影情報で検索できる |
| カメラ RAW | まずカメラの埋め込みプレビューをすぐ出し、裏でセンサーのデータから現像して差し替える。同じ名前の JPEG と組にして比べられる。`vwbatch` で現像して書き出せる |
| FITS（天体の画像） | 暗い画像を見やすく伸ばし（zscale・asinh など）、色の表とゲージを付ける。ダーク・フラットを当て、星図に写した範囲を出し、白黒の画像 2〜3 枚を位置合わせして色を合成する。一晩のサブフレームを評価して悪い画像に印を付け、位置を合わせて切り替えて見られる。画素の変換で自動で明るく見せる・GHS・ノイズ除去・デコンボリューション・星の除去と星の戻しなどの仕上げができる。ヘッダの全項目で検索できる |
| PNG | 16bit の画像を 8bit に落とさずに読み、元の値のまま測れる。10bit・12bit のモニタではその階調で描ける。テキストのチャンク（作成ソフトや説明など）をメタデータに出し、検索できる |
| WebP / GIF | アニメーションの全コマを 1 つのスロットに並べ、コマごとにファイルに書かれた長さで再生する。1 枚表示（1x1 か最大化）で開くと自動で動く。ホイールで 1 コマずつ送れる |
| TIFF | 複数ページを 1 つのスロットに並べてホイールで送る。32bit の実数や CMYK、FAX 圧縮も読む。EXIF とタグで検索できる |
| BMP | 古い 1〜32bit の BMP や RLE 圧縮も開く |
| ZIP / 7z / tar | 展開の手間なくフォルダと同じように開く（パスワード付きも）。中の画像も検索カタログに入り、見つけたものを取り出せる。中の画像にはラベルを付けられない（読むだけ） |

細かな対応範囲（ビット数・圧縮方式・拡張子）は [対応している形式の詳細](docs/manual/formats.md) にあります。

## ダウンロードとインストール

[Releases](https://github.com/xex-ken-xex/vw/releases) のページから、使っている OS のファイルをダウンロードします。正式版（vX.Y.Z）を使ってください。

| ファイル | 対象 |
| --- | --- |
| `vw-windows-x64.zip` | Windows 10 / 11（64bit） |
| `vw-linux-x64.tar.gz` | Ubuntu 22.04 以降など、x86_64 の Linux |

- **Windows**: インストーラーはありません。zip を展開して `vw.exe` をダブルクリックします。署名がないため「Windows によって PC が保護されました」と出たら **詳細情報** → **実行** で起動できます
- **Ubuntu**: `tar xzf vw-linux-x64.tar.gz && cd vw && ./install.sh` でアプリ一覧に登録されます（管理者権限は使いません）

スマート アプリ コントロールに止められたとき、画像の開き方、必要なライブラリ、アンインストール、ダウンロードしたファイルの確かめ方は [ダウンロードとインストール](docs/manual/install.md) にあります。

## はじめの 5 分

初めて使うときの流れを、ひととおり追ってみます。

### 日本語表示にする

vw は初めて起動したとき、OS の表示の言語が日本語なら日本語、それ以外なら英語で表示されます。あとから切り替えるには次のようにします。

1. 左下の歯車のボタン（または Ctrl+,）で設定を開きます
2. **Appearance**（外観）の **Language**（言語）を **日本語** にします。その場で日本語に切り替わります
3. 左上の **← 戻る** で元の画面に戻ります

この README と使い方では、日本語表示のときの名前で説明します。英語表示のときの名前は、必要に応じて括弧で添えます。

### 写真を見る

1. 左のフォルダツリーで **Home** の ▶ を押して開き、写真のフォルダ（例: `Pictures`）をクリックします
2. 右の画像ウインドウに、フォルダの中のサブフォルダと画像が 1 つずつ並びます。1 つの枠を **スロット** と呼びます
3. 画像のスロットをクリックすると、右のメタデータウインドウに撮影情報（カメラ・ISO・シャッター速度など）が出ます
4. スロットをダブルクリックすると、画像ウインドウいっぱいに大きく表示されます。もう一度ダブルクリックで元に戻ります
5. → / ← キーで、次 / 前の画像のスロットへ移ります

### タグを付けてみる

1. 設定の **フラグとタグ** の **タグ** に、使いたいタグをカンマ区切りで入れます（例: `山, 海, 花`）
2. 画像ウインドウに戻り、**T** キーを押してタグ付けモードにします。画像ウインドウの下にタグのバーが出ます
3. 画像を選んで **↑** を押すと「良い」、**↓** を押すと「悪い」のフラグが付き、次の画像へ進みます
4. **1** を押すと 1 番目のタグ（山）、**2** で 2 番目（海）が付きます
5. 左の列の漏斗のボタンを押すと、「良い」の画像だけに絞り込めます

### カタログを作ってみる

1. 設定の **データセット** の **データセットのフォルダ** に、写真をしまっている親フォルダ（例: `C:\Users\me\Pictures`）を入れます
2. フォルダツリーで、まとまりのあるフォルダ（例: `旅行2026`）を右クリック → **データセットとして登録...** を選びます
3. 名前やメモを入れて **登録** を押すと、中の画像を読んで検索カタログを作ります
4. **Ctrl+D** でデータセットの画面を開くと、登録したデータセットが並び、名前や撮影情報で探せます

詳しい使い方は、下の [使い方](#使い方) から辿れます。
