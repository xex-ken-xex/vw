# vw

Linux / Windows 向けの、起動と表示が速い画像ビューワです。Rust と egui (OpenGL) で作っています。

![画面構成](docs/screenshot.png)

- フォルダツリー、メタデータ、画像、ログの 4 つのフィールドで構成された 1 画面のアプリです
- 画像フィールドには複数の画像を並べて表示できます
- 画像に「良い / 悪い」のフラグやタグを付けて、絞り込み・書き出し・まとめて削除ができます
- 16bit 画像も 8bit に落とさずに読み込みます

| 形式 | 状態 |
| --- | --- |
| PNG（1〜16bit、グレー / RGB / アルファ / パレット） | 対応済み |
| JPEG（ベースライン / プログレッシブ、グレー / カラー / CMYK、EXIF の向きと情報） | 対応済み |
| WebP（非可逆 / 可逆、透過、EXIF の向きと情報。アニメーションは全コマを 1 つのスロットに並べ、スライドショーで再生） | 対応済み |
| カメラ RAW（Nikon NEF / NRW、Sony ARW / SR2 / SRF、富士フイルム RAF。Canon CR2 / CR3、DNG も読める）。カメラが埋め込んだプレビュー JPEG を表示し、撮影情報を出す。続けて裏でセンサーのデータを現像し、精細な画像に差し替える（現像中はスロットにフィルムの印） | 対応済み |
| BMP（1〜32bit、パレット / RLE / ビットフィールド、上下逆の BMP も） | 対応済み |
| GIF（透過、アニメーションは全コマを 1 つのスロットに並べ、スライドショーで再生） | 対応済み |
| TIFF | 予定 |

## ダウンロード

[Releases](https://github.com/xex-ken-xex/vw/releases) から、使っている OS のファイルをダウンロードします。

| ファイル | 対象 |
| --- | --- |
| `vw-windows-x64.zip` | Windows 10 / 11（64bit） |
| `vw-linux-x64.tar.gz` | Ubuntu 22.04 以降など、x86_64 の Linux |

Release は 2 種類あります。

- **vX.Y.Z**（例: v0.1.0）: 正式版。通常はこちらを使ってください
- **最新ビルド (main)**: 開発中の最新版。main ブランチが更新されるたびに自動で置き換わります

## Windows での使い方

### インストール

インストーラーはありません。zip を展開するだけで使えます。

1. `vw-windows-x64.zip` をダウンロードします
2. zip を右クリックして **すべて展開** を選び、好きな場所（例: `C:\Tools\vw`）に展開します
3. 展開したフォルダの `vw.exe` をダブルクリックすると起動します

初回起動時に「Windows によって PC が保護されました」と表示されることがあります。
これは署名のない新しいアプリに出る警告です。**詳細情報** → **実行** で起動できます。

### 画像を開く

- **起動してから開く**: 左のフォルダツリーでフォルダをクリックすると、中のフォルダと画像が右に並びます
- **ドラッグ＆ドロップ**: 画像やフォルダを `vw.exe` のアイコンに重ねて離します
- **右クリックから開く**: 画像を右クリック → **プログラムから開く** → **別のプログラムを選択** → **PC でアプリを選択する** で `vw.exe` を選びます。「常にこのアプリを使う」にすると、ダブルクリックで vw が開くようになります
- **コマンドから開く**:

  ```bat
  vw.exe C:\Users\me\Pictures
  vw.exe a.png b.png c.png
  ```

  フォルダを渡すと、そのフォルダに移った状態で起動します。
  画像を複数渡すと、それぞれ別のスロットに並べて表示します。

### スタートメニューやデスクトップに置く

`vw.exe` を右クリック → **その他のオプションを確認** → **ショートカットの作成** で作ったショートカットを、
デスクトップや `%APPDATA%\Microsoft\Windows\Start Menu\Programs` に置きます。

### アンインストール

展開したフォルダを削除し、設定と状態のフォルダ（`%APPDATA%\vw`）も消してください。レジストリは使っていません。

## Ubuntu での使い方

### インストール

```sh
tar xzf vw-linux-x64.tar.gz
cd vw
./install.sh
```

`install.sh` は次のことを行います（管理者権限は使いません）。

- `vw` を `~/.local/bin/vw` に置く
- アプリ一覧に「vw」をアイコン付きで登録し、PNG・JPEG・WebP・GIF・BMP・カメラ RAW の「別のアプリケーションで開く」に出るようにする

インストールせずに、展開したフォルダで `./vw` を実行して使うこともできます。

### 画像を開く

- **アプリ一覧から**: 「vw」を起動し、左のフォルダツリーでフォルダをクリックします
- **ファイルマネージャーから**: 画像を右クリック → **別のアプリケーションで開く** → **vw**
- **端末から**:

  ```sh
  vw ~/Pictures
  vw a.png b.png c.png
  ```

### 必要なライブラリ

デスクトップ版の Ubuntu なら追加のインストールは不要です。
サーバー版や最小構成で起動しない場合は、次を入れてください。

```sh
sudo apt install libxkbcommon-x11-0 libgl1 libegl1 libxcursor1 libxrandr2 libxi6 fonts-noto-cjk
```

`fonts-noto-cjk` はファイル名などの日本語表示に使います。

### アンインストール

```sh
./install.sh --uninstall
```

## 画面と操作

```
┌ File  View  Labels  Image ──────────────────────────────────────┐
│ Folders  │  Images（スロットを並べる）              │ Metadata │
│          │  ┌─ img01.png ── 32% ⛶ 1:1 × ┐┌─ ... ─┐  │          │
│          │  │                      3 / 12 ││       │  │          │
│          │  └──────────────────────────────┘└───────┘  │          │
├──────────┴──────────────────────────────────────────┴──────────┤
│ Log                                                              │
└──────────────────────────────────────────────────────────────────┘
```

| 場所 | 内容 |
| --- | --- |
| Folders | フォルダと ZIP の木。クリックしたフォルダへ移り、中身を右の Images に並べます。ホームと、Windows はドライブ、Linux は `/` から辿れます |
| Images | 画像を表示する枠（スロット）を並べます。並べ方は **View → Layout** で 2 x 2 などに固定できます（既定は枚数に応じて自動） |
| Metadata | 選んでいるスロットの画像の、ファイル情報と画像内の情報（EXIF など） |
| Log | 読み込みにかかった時間やエラー。エラーは赤字です |

各欄は **View** メニューか Ctrl+1〜4 で表示・非表示を切り替えられ、境目はドラッグで動かせます。

### スロットの見方

- 上の帯（ヘッダ）の左にファイル名、右に表示倍率と 2 つのボタン（⛶ = スロットに合わせる、1:1 = 実寸）と × が並びます
- 1 つのスロットに複数の画像が入っているとき（フォルダをまとめて読んだ・アニメーション・複数フレーム）は、
  画像の右上に「何枚目 / 全部で何枚」が出ます
- 選んでいるスロットは枠が青くなります
- フラグを付けた画像は、ヘッダの下端が緑（良い）か赤（悪い）になり、右側にフラグとタグが出ます

### フォルダを開く

| 操作 | 動作 |
| --- | --- |
| ツリーでフォルダをクリック | そのフォルダへ移り、中のサブフォルダ・ZIP・画像を 1 つずつスロットに並べる。▶ のクリックは開閉だけ |
| Alt を押しながらフォルダをクリック | 画像を 1 つのスロットにまとめて読む |
| Backspace / File → Up one folder | 1 つ上のフォルダへ移る |
| フォルダのスロットをダブルクリック | そのフォルダの画像をそのスロットにまとめて読む（サブフォルダがあれば、その画像も読むか尋ねる） |
| フォルダのスロットのヘッダ右の矢印 / Enter | そのフォルダへ移る（矢印はマウスを乗せたときに出る） |
| ZIP・7z をクリック・ダブルクリック | 展開してツリーの先頭に別のルートとして開き、その中へ移る（下記） |
| エクスプローラなどからファイルやフォルダをドロップ | そのフォルダへ移る（ファイルならその画像を選ぶ） |

**ZIP・7z について**: 一時フォルダに展開して開きます。パスワード付き（ZIP は ZipCrypto と AES、7z は AES）はパスワードを尋ねます（パスワードは覚えません）。中の画像は読むだけで、フラグやタグは付けられません。
ツリーの ZIP のルートを右クリック →「ZIP を閉じる」で閉じると、展開したファイルを消します（vw を終了しても消えます）。

### 画像を見る

| 操作 | 動作 |
| --- | --- |
| → / Space、← | 次 / 前の画像のスロットを選ぶ（フォルダのスロットは飛ばす。スロットの中身は変わらない） |
| マウスホイール | まとめて読んだスロットでは次 / 前の画像。1 枚ずつのスロットが並んでいるときは次 / 前のスロットへ移り、1 枚だけ表示しているとき（1x1 か最大化）は次 / 前の画像 |
| Ctrl+→ / Ctrl+← | 次 / 前のスロットを選ぶ（フォルダのスロットも含む） |
| 左ドラッグ | 画像を動かす |
| 右ドラッグ（上下） / Ctrl+ホイール / タッチパッドのピンチ | 拡大・縮小（右ドラッグは押した位置、それ以外はマウスの位置が中心） |
| 0 / Ctrl+0 / + / - | スロットに合わせる / 実寸 / 拡大 / 縮小（ヘッダのボタンでも同じ） |
| ダブルクリック / Enter | スロットを画像欄いっぱいに最大化・元に戻す |
| 画像を右クリック | スロットに合わせる・コピー・RAW の現像（カメラ RAW のとき） |
| Ctrl+C | 選んでいるスロットの画像をクリップボードへコピー |
| P | スライドショーの再生・一時停止。スロットを最大化し、下の再生バーで FPS と最後の動き（ループ / 止める / 往復）を選ぶ |
| D | カメラ RAW をセンサーのデータから現像する（設定で裏の現像を切ったとき） |

- ホイールで前後の画像に送っても、倍率と位置はそのままです（設定の **Keep zoom when stepping** で切れます）
- 画像はスロットいっぱいに合わせて表示します

### スロットとレイアウト

| 操作 | 動作 |
| --- | --- |
| Alt+0 〜 Alt+7 / View → Layout | レイアウト（自動 / 1x1 / 1x2 / 2x1 / 2x2 / 3x3 / 4x4 / カスタム） |
| PageDown / PageUp | レイアウトを固定していてスロットが入りきらないとき、次 / 前のページ（画像欄の右下にページが出る） |
| Ctrl+N / File → New slot | 空のスロットを足す |
| Ctrl+W / スロット右上の × | スロットを閉じる |
| Ctrl+Shift+W / File → Close all slots | すべてのスロットを閉じる |

### ファイルの移動・コピー

| 操作 | 動作 |
| --- | --- |
| スロットのヘッダ（名前の帯）を、ツリーのフォルダかフォルダのスロットへドラッグ | 画像をそのフォルダへ移動（確認あり）。フラグとタグも一緒に移る |
| 同じく Ctrl を押しながらドラッグ | コピー（確認なし） |

同じ名前のファイルが移す先にあるときは、上書きせずに何もしません（ログに出ます）。

### フラグとタグ

画像に「良い / 悪い」のフラグと、設定で決めたタグ（例: cat, dog）を付けられます。
T キーか左の列のタグのボタンでタグ付けモードにすると、次のキーが使えます。

| 操作 | 動作 |
| --- | --- |
| ↑ / ↓ | 良い / 悪いのフラグ。もう一度押すと外す |
| 1 〜 9 | 設定の **Tags** の 1 〜 9 番目のタグを付ける・外す |

- 付けると次の画像へ進みます（設定の **Next image after labeling** で止められます）
- 画像の下のバーに今の画像のフラグとタグが出て、クリックでも付け外しできます
- ラベルはフォルダごとの `.vw-labels.json` に保存します（画像ファイルは書き換えません）。
  書き込めないフォルダのラベルは、設定ファイルの隣の `labels` フォルダに保存します

**絞り込み**: **Labels** メニューか左の列の漏斗のボタンで、良いだけ・悪いだけ・フラグなしだけ・タグ X だけを表示します。
ボタンは押すたびに すべて → 良い → 悪い → フラグなし → 各タグ → すべて と切り替わり、色で今の絞り込みが分かります。
絞り込みはツリー、画像送り、フォルダの読み込み、スライドショーに効きます。

**書き出し**: **Labels → Export images...**（Ctrl+E）で、今いるフォルダ（サブフォルダも含められます）の絞り込んだ画像を
別のフォルダへコピーするか、パス・フラグ・タグの一覧を CSV / JSONL で書き出します。

**悪い画像を消す**: **Labels → Move bad images to trash...** で、今いるフォルダの悪いフラグの画像をまとめてごみ箱へ送ります。
送る前に枚数と名前を確認します。サブフォルダの画像は対象にしません。ごみ箱から元に戻せます。

### データセット

フォルダを「データセット」として登録すると、その中の画像（ZIP / 7z の中も）のメタデータを集めた
**検索カタログ**（フォルダ直下の `vw-search-catalog.json`）を作ります。

- **登録**: ツリーのフォルダを右クリック → **Register as dataset...**。名前・メモ・タグと、
  設定の **Dataset fields** で足した項目（入手元など）を入れて **Register** を押します
- **編集・更新**: 登録したフォルダを右クリック → **Edit dataset...** / **Update dataset**。
  更新はフォルダ以下の全ファイルを読み直し、増えた・消えた・変わったファイルの数をログに出します。名前やメモはそのままです
- パスワード付きの ZIP / 7z はパスワードを聞きます（保存しません）。**Skip** でその ZIP を対象外にし、読めなかったものとして検索カタログに残します
- データセットの中に別のデータセットを登録できます。外側のデータセットは内側のファイルも含みます。書き込めないフォルダは登録できません
- 2KB を超える値は、値の代わりに長さだけを入れます
- メタデータは「種類・キー・値」で持ちます。種類はメタデータ欄のグループ名を小文字にしたもの（`exif` など）と、
  形式・幅・高さ・ビット深度の `image` です

**探す**: 左端の列のデータベースのボタンか **View → Open/close datasets**（Ctrl+D）で、設定の **Dataset folders** 以下の
データセットを一覧にした画面に切り替わります（開くたびに探し直し、**Reload** でも探し直せます）。

- 検索欄に語を入れると、名前・メモ・タグ・項目・メタデータのどれかに含むデータセットに絞ります。空白で区切った語はすべてを満たすもの
- **Advanced** で条件を足せます。対象（名前・メモ・タグ・項目・メタデータ）と、含む・一致・正規表現・数値の範囲・存在する を選びます。
  メタデータの条件は同じファイルで満たすものを数え、表の **Hits / files** に出します。キーは候補から選べます
- 行を選ぶと右に詳細が出ます。**Edit...** / **Update** はここからも行えます。**Update all** は表に出ているものをすべて更新します
- **Show**（または行のダブルクリック）で、そのデータセットのフォルダへ移って画像を読み込みます。検索カタログにあるのに
  見つからないファイルがあれば、ログに出して更新を促します
- **Extract...** で、データセットのファイルを別のフォルダ（空のフォルダか、まだないフォルダ）へフォルダ構成のまま写します。
  ZIP / 7z の中のファイルは展開して、`data.zip` のようにアーカイブと同じ名前のフォルダの下に置きます。
  出力先には新しい検索カタログを作り、名前などはダイアログで変えられます。元のデータセットは詳細の **Extracted from** に出ます。
  別のデータセットの中に取り出したときは、その外側のデータセットを更新するか聞きます
- 入れ子のデータセットは、場所で並べたときに外側の下に字下げして出ます

### 自動で行うこと

- **前回の状態を戻す**: ウインドウの位置と大きさ、ツリーの開いていたフォルダ、いたフォルダを次の起動時に戻します。
  モニタの構成が変わったときは OS の標準の位置に出ます（Wayland では大きさだけ）
- **フォルダの監視**: 今いるフォルダに画像が増えたらスロットを足し、消えたらスロットを閉じます。
  最後の画像を表示しているスロットは新しい画像に移ります（1 枚だけ表示しているときは常に新しい画像へ）。
  表示中の画像が上書きされたら、倍率と位置を保ったまま読み直します。設定の **Auto reload** で止められます

### キーの一覧（そのほか）

| キー | 動作 |
| --- | --- |
| Ctrl+1 / 2 / 3 / 4 | フォルダツリー / メタデータ / 画像 / ログの表示切替 |
| Ctrl+D | データセットの画面を開く・閉じる |
| Ctrl+, / 左下の歯車 | 設定画面を開く・閉じる |
| Ctrl+Q / File → Quit | 終了 |
| ログの行をクリック → Ctrl+C / ログを右クリック | その行をコピー（右クリックの「すべてコピー」でログ全体） |

キーの割り当ては設定画面の **Keyboard shortcuts** で変えられます。メニューの右側には今のキーが出ます。

### 設定

左下の歯車（または Ctrl+,）で設定画面に切り替わります。上の検索欄に語を入れると項目を絞り込めます。
変更はその場で反映され、自動で保存されます。主な項目は次のとおりです。

| 項目 | 内容 |
| --- | --- |
| Theme / Language / UI scale | 見た目（OS に合わせる・ダーク・ライト）、言語（English / 日本語）、文字とアイコンの大きさ |
| Background color | 画像の背景色（`#RRGGBB`、空欄でテーマの既定色） |
| Tags | タグの一覧（カンマ区切り）。先頭の 9 個が数字キー 1〜9 に対応 |
| Sort order | ツリーとスロットの並び順（既定は更新日時の新しい順） |
| Auto reload | フォルダの監視（既定で有効） |
| Develop RAW in the background | カメラ RAW を裏で現像する（既定で有効） |
| Dataset folders / Dataset fields | データセットを探すフォルダ（1 行に 1 つ）と、データセットに書き込む項目（カンマ区切り） |
| Keyboard shortcuts | 操作ごとのキー。**+** を押してからキーを押すと追加、キーをクリックすると削除。1 つの操作に複数のキーを割り当てられます |

- 別の操作で使っているキーは割り当てられません
- OS がよく使うキー（Alt+F4 など）は割り当てられますが、オレンジ色の警告が出ます。OS が先に使うと vw には届きません
- Ctrl+C / Ctrl+X / Ctrl+V はクリップボード用のため割り当てられません

設定ファイルは次の場所にあります。設定画面の **Open settings file** で、既定のエディタで開けます。
エディタで保存すると、vw が自動で読み直します。

| OS | 場所 |
| --- | --- |
| Windows | `%APPDATA%\vw\settings.toml` |
| Linux | `~/.config/vw/settings.toml`（`XDG_CONFIG_HOME` があればその下） |

- 書かれていない項目は既定値で動きます
- 値が壊れている項目は、その項目だけを既定値にして、ログに赤字で理由を出します
- 壊れたファイルを設定画面からの変更で上書きするときは、元のファイルを `settings.toml.bak` として残します
- 同じフォルダの `state.toml` は終了時の状態（ウインドウ・ツリー）で、vw が自動で書き換えます

---

## 困ったとき

| 症状 | 対処 |
| --- | --- |
| ファイル名や日本語表示が □ になる | Windows は通常起きません。Linux は `sudo apt install fonts-noto-cjk` を実行して再起動してください（日本語の字形のフォントだけを使います。中国語フォントだけが入っている環境では □ になります） |
| Linux で `libxkbcommon-x11.so could not be loaded` と出て起動しない | `sudo apt install libxkbcommon-x11-0` |
| 起動直後に落ちる / 画面が真っ黒 | OpenGL 2.0 以上が必要です。グラフィックドライバを更新してください。リモートデスクトップや仮想マシンでは、Linux なら `LIBGL_ALWAYS_SOFTWARE=1 vw` で動くことがあります |
| 大きな画像が粗く見える | 一辺 8192 ピクセルを超える画像は、GPU の制限のため縮小して表示しています（ログに表示されます） |
| 16bit 画像が暗い | 有効ビット数が記録されていない 16bit 画像は、16bit 全体を階調として表示します。階調の調整機能は今後追加します |

## 開発とビルド

### 必要なもの

| もの | 用途 |
| --- | --- |
| Rust（stable、rustup で導入） | コンパイラとビルドツール（cargo） |
| Windows: Visual Studio 2022 Build Tools の「C++ によるデスクトップ開発」 | Rust がリンカとして使います |
| Linux: build-essential | C コンパイラとリンカ |
| Git | ソースの取得 |

### 環境を自動で揃える

リポジトリを取得してから、OS に合ったスクリプトを実行します。
必要なものを入れたうえで、リリースビルドとテストまで行います。何度実行しても問題ありません。

**Windows**

```bat
git clone https://github.com/xex-ken-xex/vw.git
cd vw
scripts\setup-windows.bat
```

`scripts\setup-windows.bat` はエクスプローラーからダブルクリックしても動きます。
winget で Visual Studio Build Tools、Git、rustup を入れるため、途中で管理者権限の確認が出ます。
Build Tools の導入には数 GB のダウンロードと 10〜30 分ほどかかります。
Git がまだない場合は、先に [Git for Windows](https://git-scm.com/download/win) を入れるか、
GitHub の **Code → Download ZIP** でソースを取得してください。

**Ubuntu**

```sh
git clone https://github.com/xex-ken-xex/vw.git
cd vw
./scripts/setup-ubuntu.sh
```

`sudo` のパスワードを聞かれます。apt で必要なパッケージを入れ、rustup で Rust を入れます。

どちらも、環境だけ揃えてビルドしない場合は `-NoBuild`（Windows）/ `--no-build`（Ubuntu）を付けます。

### ビルドと実行

```sh
cargo run --release -- [フォルダ または 画像ファイル ...]   # ビルドして起動
cargo build --release                                       # 実行ファイルだけ作る
```

実行ファイルは `target/release/vw`（Windows は `target\release\vw.exe`）にできます。
開発中は `--release` なしの `cargo run` でも動きます。依存ライブラリは最適化してビルドするので、
デバッグビルドでも画像の読み込みはそれほど遅くなりません。

### テストとチェック

プルリクエストを出す前に、CI と同じ次のチェックを通してください。

```sh
cargo fmt --all --check                      # 書式
cargo clippy --all-targets -- -D warnings    # 静的解析（警告もエラー扱い）
cargo test                                   # 自動テスト
```

### リポジトリの構成

```
crates/
  vw-core/   共通メモリ形式 (VwImage)、プラグインの定義 (DecoderPlugin)、描画用変換
  vw-png/    PNG プラグイン
  vw-jpeg/   JPEG プラグイン
  vw-bmp/    BMP プラグイン
  vw-webp/   WebP プラグイン
  vw-gif/    GIF プラグイン
  vw-raw/    カメラ RAW プラグイン（rawler、LGPL-2.1）
  vw-app/    アプリ本体（実行ファイル vw）
docs/        設計資料
scripts/     開発環境の構築スクリプト
packaging/   配布物に同梱するファイル
```

設計の詳細は [docs/architecture.md](docs/architecture.md)、
コーディングのルールは [CLAUDE.md](CLAUDE.md) を参照してください。

### 新しい形式を追加する

1. `crates/vw-<形式名>` を作り、`vw_core::DecoderPlugin` を実装します
   - `probe` でファイル先頭のマジックナンバーを判定し、`decode` で `VwImage` を返します
   - 階調は落とさずに返します（16bit なら `PixelData::U16`）
2. ルートの `Cargo.toml` の `members` に追加します
3. `crates/vw-app/src/main.rs` の `registry()` に 1 行追加して登録します

`crates/vw-png` が実装例です。

### リリース

CI（GitHub Actions）が Linux と Windows でチェック・テスト・ビルドを行い、次のときに Release へ載せます。

| きっかけ | Release |
| --- | --- |
| main ブランチへの push（プルリクエストのマージ） | 「最新ビルド (main)」を置き換える |
| `v` で始まるタグの push | そのタグ名の正式版を作る |
| Actions の画面から CI を手動実行（版番号を入力） | main の最新コミットにタグを付け、正式版を作る |

正式版を出すときは、`Cargo.toml` の `version` を上げてから、次のどちらかを行います。

- GitHub の **Actions** → **CI** → **Run workflow** で、Branch を `main` のまま版番号（例: `v0.1.0`）を入れて実行する
- 手元の main でタグを付けて push する

```sh
git tag v0.1.0
git push origin v0.1.0
```
